# Ultimate Fist

This mod is a reimplementation of the Ultimate Fist mod for Better Than Adventure.

I really enjoyed this mod when I discovered it in 2012 and I believe BTA needs it too!

This is my first public mod and my Java skills aren't the best, so suggestions, bug reports, and contributions are very welcome. :)
